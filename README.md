# Codecoach

 Project Name: Coding Coach

 Goal:

A web platform that connects students (mentees) with experienced developers (mentors) for coding guidance, online sessions, and skill improvement.


---

 Main Users:

Mentee: Learns coding, books sessions.

Mentor: Teaches coding, manages schedule.

Admin: Handles users, reports, and payments.



---

 Key Features:

Create account and profile (mentor or mentee)

Search mentors by skill, rating, or price

Book online sessions and chat

Leave ratings and reviews

Admin dashboard to monitor activity



---

 Technology Used:

Frontend: React or Next.js (for website)

Backend: Node.js with Express

Database: PostgreSQL

Payments: Stripe

Hosting: Vercel or Render



---

 Benefits:

Helps learners find experts easily

Provides mentors a way to earn and share knowledge

Builds a global learning community
